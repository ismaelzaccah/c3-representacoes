# Requisitos não funcionais verificáveis

Status PROPOSTO • ESF-C3-0.1 • 10/11/2026.

Metas numéricas desta versão são propostas técnicas sujeitas à arquitetura, orçamento e carga homologados. P0/P1 indicam prioridade de controle dentro do MVP. Bases F01 §7, F14/F18/F23/F29 e convenções CT. Responsável pela demonstração técnica Ismael. Validação funcional Caio. Cada linha define um critério CA-RNF correspondente ao ID.

## Referências técnicas

A meta de acessibilidade usa a recomendação e os critérios aplicáveis da WCAG 2.2. [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)

O identificador CNPJ deve suportar o formato numérico existente e o alfanumérico anunciado pela Receita Federal, conforme D-02. Procedimento de validação será conferido com casos oficiais na implementação. [Receita Federal — CNPJ alfanumérico](https://www.gov.br/receitafederal/pt-br/acesso-a-informacao/acoes-e-programas/programas-e-atividades/cnpj-alfanumerico)
